CSV Preflight: CSV validator for Mac

Check a CSV before you import it into a spreadsheet, database or other tool. Open it on your Mac and see which rows and columns need attention.

View on the Mac App Store

macOS 14 or later · English and Japanese · One-time purchase

What CSV Preflight checks

  • Delimiter, line endings, quoting and inconsistent column counts.
  • Duplicate rows, empty or repeated headers, and invisible characters.
  • Duplicate keys, missing values, character limits and UTF-8 byte limits in a selected column.

The app reads UTF-8 and BOM-marked UTF-16, with a 256 MB file limit. Inspection runs locally and leaves the source file untouched.

When a CSV import fails

Start with the row and column in the report. A comma inside an unquoted value can create an extra column. An invisible character can make two keys look identical. Use the CSV report to locate the affected values before retrying the import.
