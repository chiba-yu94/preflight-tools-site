File Transfer Preflight: filename and path checker for Mac

Check a folder or ZIP before handing it to someone on Windows or moving it to cloud storage. Find names and paths the destination may reject.

View on the Mac App Store

macOS 14 or later · English and Japanese · One-time purchase

What File Transfer Preflight checks

  • Unsupported filename characters, reserved names, trailing periods and spaces.
  • Long filenames and destination paths. Enter an optional destination root to estimate the final path.
  • Case or Unicode normalization collisions, links, empty folders and macOS metadata.

Inspection runs locally and reads ZIPs without extracting them. The app leaves the original files untouched.

Before sending a ZIP to a Windows user

Choose the Windows / Office profile and enter the recipient’s destination root if you know it. Review incompatible names and long paths, then export a CSV or HTML report for the handoff.
