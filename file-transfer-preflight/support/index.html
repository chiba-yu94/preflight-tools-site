File Transfer Preflight · 2026-10-09

Choose a local folder or ZIP, select Windows / Office, OneDrive / SharePoint, or Cross-platform ZIP, then Scan. Folder contents are scanned; the selected folder's own name is not included.

Destination root is optional. For Windows, enter the recipient's local path. For cloud storage, enter a decoded library path, not a full URL or local sync folder. Empty root gives a lower-bound estimate. Limits differ by recipient app and organization.

Results explain name/path issues and suggest actions. The app never renames, deletes, moves or cleans files. Export CSV or standalone HTML from Export Report. Reports use English technical labels and contain no file bodies.

Scans are bounded to 100,000 entries, 128 path components, 4096 UTF-8 bytes per relative path, 64 MB total name bytes, 20,000 findings, a 2 GB ZIP and 1 TB total declared ZIP sizes. Unsupported or oversized input reports failure or incomplete coverage. ZIP payload integrity, aliases inside ZIPs, every visual lookalike, recipient permissions and tenant policies are not validated. No finding is not a transfer guarantee.

Contact support with your app version, macOS version and reproduction steps using synthetic examples. Do not attach private data.
