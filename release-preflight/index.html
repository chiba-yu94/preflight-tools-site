What Release Preflight checks

  • Patterns resembling API keys, access tokens and private keys. Findings mask secret values.
  • Property lists, app entitlements, development endpoints and unneeded release files.
  • Dependencies from supported manifests and lockfiles, with optional OSV lookups for known advisories.

File inspection runs on your Mac. Optional OSV lookup sends supported package details after you enable it. Checks cover supported rules and file types.

What to inspect in an Xcode archive

Select the archive or exported app you intend to distribute. Review credentials and development endpoints in bundled configuration files, then save the results as HTML or JSON for review.
