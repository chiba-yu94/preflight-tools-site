File Transfer Preflight｜ファイル名とパス長の検査

MacからWindowsやクラウドストレージへフォルダやZIPを渡す前に、使えないファイル名や長いパスを確認できます。

Mac App Storeで見る

macOS 14以降 · 日本語・英語 · 買い切り

確認できる項目

  • 使えない文字、予約名、末尾の空白やピリオド。
  • 長いファイル名とパス。受け渡し先のルートを指定すると、転送後のパス長を概算できます。
  • 大文字・小文字やUnicode表現の違いによる名前の衝突、リンク、空フォルダ、Macのメタデータ。

検査はMac内で行い、ZIPは展開せずに読み取ります。元のファイルはそのままです。

Windows利用者にZIPを送る前に

Windows / Officeプロファイルを選び、展開先が分かる場合はルートパスを指定します。相手側で問題になりやすい名前や長いパスを確認し、必要に応じて結果をCSVまたはHTMLで保存します。
