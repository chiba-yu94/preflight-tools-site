File Transfer Preflight · 2026-10-09

ローカルのフォルダまたはZIPを選び、転送先のプロファイルを選択して「検査」を押します。フォルダは中身を検査し、選択したフォルダ自身の名前は含めません。

転送先のルートパスは任意です。Windowsなら相手のローカルの保存先、クラウドならデコード済みのライブラリのパスを入力します。クラウドのURLやローカルの同期フォルダは指定しません。空欄の場合は相対パスのみの概算です。実際の制限は相手のアプリや組織によって異なります。

検出結果には理由と対処の提案を表示します。名前の変更、削除、移動、ZIPの整理は行いません。「レポートを書き出す」からCSV・HTMLを保存できます。レポートの技術的な見出しは英語で、ファイル本体は含みません。

上限は100,000項目、128階層、相対パス4,096 UTF-8バイト、名前合計64 MB、20,000件の検出、ZIP本体2 GB、ZIP内の申告サイズ合計1 TBです。未対応の入力や上限超過はエラーまたは検査未完了として示します。ZIPの内容の完全性、ZIP内のエイリアス、見た目が似たすべての文字、相手のアクセス権や組織の設定は検証しません。問題が検出されなくても、転送成功を保証しません。

お問い合わせにはアプリとmacOSのバージョン、再現手順を添えてください。サンプルには架空のデータを使い、機密情報を添付しないでください。
