File Transfer Preflight · 2026-10-09

File Transfer Preflightは、明示的に選択したフォルダまたはZIPだけをMac内で検査します。ネットワーク通信、アカウント、クラウドへのアップロード、アクセス解析、テレメトリ、広告、トラッキング、外部APIはありません。

ファイル名・パス・メタデータを検査します。ファイルの送信、リンクやエイリアスのリンク先へのアクセス、ZIPの展開、元のファイルの変更は行いません。結果はメモリに保持し、検査履歴は保存しません。

CSV・HTMLレポートは、指定した保存先にだけ書き出します。レポートには対象の名前、パス、転送先のルートパス、検出結果を含みますが、ファイル本体は含みません。名前やパスにも機密情報が含まれる場合があるため、共有前に内容をご確認ください。

このサイトはGitHub Pagesで配信し、独自のCookieやアクセス解析は使用しません。GitHubやAppleのサービスには各社のプライバシーポリシーが適用されます。サポートに送信した情報はお問い合わせへの回答に使用します。機密ファイルやレポートは送信しないでください。
